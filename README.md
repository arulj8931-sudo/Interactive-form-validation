Interactive Form Validation
An interactive front-end web project demonstrating real-time form validation with a Red • Blue • White theme.

🚀 Features
Live input validation for name, email, phone, password
Password strength indicator
Responsive and accessible design
Toast notification on successful form submission
🧰 Tech Stack
HTML5
CSS3 (custom styling and layout)
JavaScript (ES6)
🎨 Theme Colors
Red #e63946
Blue #1d4ed8
White #ffffff

Screenshot

⚙️ How to Run
Download or clone this repository
Open index.html in your browser
That’s it — the form runs fully client-side
